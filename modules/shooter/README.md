# 发射模块（Shooter）

这个模块负责把发射命令和目标速度转换成电机力矩输出，完成摩擦轮控速、拨盘拨弹和堵转清理。

## 模块分为哪几层

```text
应用层：决定命令和目标速度，处理热量、弹量、弹速自适应
                         ↓
Module：对外端口、最新输入更新、周期接线和力矩输出
                         ↓
Shooter：触发唤醒、摩擦轮和拨盘总体控制
                         ↓
Fric：单个摩擦轮的速度控制    Feed：拨盘控制、复位、退弹和重载
                         ↓
pid.hpp：适配算法库 PID 的参数、周期、死区和限幅
```
